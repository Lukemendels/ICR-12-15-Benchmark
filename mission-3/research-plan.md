# Mission 3 research plan

The primary estimand is observable consistency of TSA burden and cost methods for comparable component activities. Differences are classified only after examining activity scope, actor, period, lifecycle, mode, occupation, vintage and evidence basis. No agency or office ranking, causal production-history inference, or UI is in scope.

## Authoritative inputs and protection

Mission 1 M1-1.0.0, rubric 1.0.0 and canonical model 0.5.0 remain frozen. Reuse `icrs/*/extraction.json`, raw statements, `data/sources.jsonl`, `data/calculation-checks.csv` and exemplar/catalog records by reference. All Mission 3 mutations are confined to `mission-3/`, `evidence-graph/` and `analysis/`. GitHub base commit and blob identities establish the pre-mission state. Earlier reports remain untouched.

## Sequence

1. Enumerate official TSA packages received September 9, 2021–September 9, 2026, cross-check active controls, and inspect control histories. Record inaccessible documents and exclusions explicitly. Pending requests remain separate from approved current inventory.
2. Commit architecture before large extraction. Retrieve all qualifying accessible Supporting Statements; select immediately preceding usable versions for baseline/lineage comparisons. Preserve original files or exact archived source text with identity and hashes.
3. Normalize activity evidence in batches: security programs; credentialing; operational/reporting/system access; other shapes. Published observations remain separate from semantic normalization. Record extraction coverage, not merely download counts.
4. Build deterministic graph and arithmetic library; use inspectable comparisons and family-specific caveats. Reuse validated Mission 1 arithmetic with original dispositions.
5. Challenge apparent inconsistencies; inspect prior versions and explanatory scope. Query frozen federal methods only for identified TSA questions.
6. Freeze only after coverage, two stable extraction batches, challenge, structural/provenance/epistemic validation and a complete Mission 4 handoff. If evidence is unavailable, bound claims explicitly; never represent incomplete extraction as saturation.
