# Shape taxonomy — initial

Evidence-derived initial collection archetypes: security-program compliance; credentialing/security threat assessment; operational reporting; claims; cybersecurity compliance. Activity labels include application, enrollment, renewal, amendment, review, recordkeeping, data entry, appeal, coordinator update, assessment, reporting and verification. Expand only when an observed task does not fit without erasing its meaning.

Both collection and activity shapes carry respondent type, regulated population, obligation type, actor, interaction mode/channel, frequency, recurrence, complexity, labor role, approval requirement, technology dependence, public security context, evidence basis and lifecycle. Unobserved values remain explicit unknowns. Detailed normalized records and taxonomy updates follow actual extraction batches.
